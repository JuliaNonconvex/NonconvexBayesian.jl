# NonconvexBayesian.jl

Bayesian optimization

Gaussian process surrogates with acquisition-function-driven constrained Bayesian optimization.

NonconvexBayesian.jl is part of the [JuliaNonconvex](https://github.com/JuliaNonconvex) ecosystem built on [NonconvexCore.jl](https://github.com/JuliaNonconvex/NonconvexCore.jl).

## Documentation

The full documentation is available at [https://julianonconvex.github.io/NonconvexBayesian.jl/stable](https://julianonconvex.github.io/NonconvexBayesian.jl/stable) (stable) and [https://julianonconvex.github.io/NonconvexBayesian.jl/dev](https://julianonconvex.github.io/NonconvexBayesian.jl/dev) (development).

## Installation

```julia
using Pkg
Pkg.add("NonconvexBayesian")
```
